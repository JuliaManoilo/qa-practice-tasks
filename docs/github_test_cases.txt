TC-01 - Реєстрація через email на головній сторінці GitHub


Назва тест-кейсу: Реєстрація через email на головній сторінці GitHub


Передумови: Користувач не авторизований. Відкрита головна сторінка https://github.com/


Тестові дані: Email: testuser@example.com


Кроки / куди вписувати:
1. Відкрити сайт GitHub.
2. Знайти поле для введення email на головній сторінці.
3. Вписати email у поле Email address.
4. Натиснути кнопку Sign up for GitHub.


Очікуваний результат: Користувача перенаправляє на сторінку реєстрації. Введений email підставлений або система пропонує продовжити створення акаунта.
Статус: Pass / Fail - вписати після виконання тесту

TC-03 - Перевірка повідомлення при вході з неправильними даними

Назва тест-кейсу: Перевірка повідомлення при вході з неправильними даними

Передумови: Користувач не авторизований. Відкрита сторінка Sign in.

Тестові дані: Username/email: wronguser@example.com; Password: wrongPassword123

Кроки / куди вписувати:
1. Відкрити сторінку Sign in.
2. Вписати неправильний email у поле Username or email address.
3. Вписати неправильний пароль у поле Password.
4. Натиснути кнопку Sign in.

Очікуваний результат: Користувач не входить в акаунт. З’являється повідомлення про неправильний логін або пароль.
Статус: Pass / Fail - вписати після виконання тесту
