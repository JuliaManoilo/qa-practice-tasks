# 🚀 GitHub UI Automation Tests (WebdriverIO)

This project contains automated UI tests for GitHub using WebdriverIO.

## 📌 Project Overview

The goal of this project is to practice and demonstrate UI test automation skills:
- Writing end-to-end tests
- Using Page Object Model (POM)
- Working with selectors (CSS, XPath)
- Organizing test structure
- Creating test documentation and screenshots

---

## 🛠 Tech Stack

- JavaScript
- WebdriverIO
- Mocha
- Node.js

---

## 📂 Project Structure
│
├── test/ # Main automation tests
├── practice/ # Practice tasks and exercises
├── docs/ # Screenshots and documentation
├── wdio.conf.js # WebdriverIO configuration
└── package.json

---

## ▶️ How to Run Tests

Install dependencies:
npm install

Run tests:
npm run test
